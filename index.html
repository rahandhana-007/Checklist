Cara pakai EUDR Farmer Data Management

  • Ketuk kotak centang untuk menandai pekebun sudah selesai.
  • Pencarian hanya memakai SH ID.
  • Salin ID / password sekali ketuk.
  • Progres disimpan ke Supabase, jadi tetap ada di Vercel dan perangkat lain.

Hubungkan Supabase

Agar centang, GeoJSON, dan foto tersimpan di cloud, jalankan SQL sekali di SQL Editor, lalu tes koneksi.

Buka Supabase → SQL Editor → New query → tempel SQL di bawah → Run. SQL ini membuat tabel progres, tabel file, dan bucket Storage. Lalu klik Tes koneksi.
